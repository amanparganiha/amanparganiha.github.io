
# AI/ML & Data Scientist Portfolio Website

## Design Direction
- **Clean & minimal** aesthetic with a professional, modern feel
- Light/neutral color palette with subtle accent colors (e.g., soft blue or indigo tones fitting the AI/data theme)
- Subtle animations: smooth page transitions, gentle hover effects, and fade-in on scroll
- Responsive design for desktop, tablet, and mobile

## Pages

### 1. Home
- Hero section with your name, title ("AI/ML Engineer & Data Scientist"), and a brief tagline
- Subtle animated background element (e.g., soft gradient or abstract data-inspired pattern)
- Quick highlights: key stats or specializations (e.g., "5+ years in ML", "20+ models deployed")
- Call-to-action buttons linking to Resume and Projects
- Short "About Me" section with a professional summary

### 2. Resume
- Clean timeline layout for work experience
- Education section
- Skills section with categorized skill tags (ML frameworks, programming languages, cloud tools, etc.)
- Downloadable PDF resume button
- Certifications and achievements

### 3. Projects
- Grid/card layout showcasing ML/AI projects
- Each card: project image/thumbnail, title, short description, tech stack tags
- Click to expand for detailed view with problem statement, approach, results
- Filter by category (e.g., NLP, Computer Vision, Data Analysis)

### 4. Blogs
- List/card layout for blog posts
- Each post: title, date, short excerpt, read time, category tag
- Full blog post view with formatted content
- Static content — posts hardcoded in the codebase

### 5. Contact
- Contact form (name, email, message) with validation and success feedback
- Social media links (GitHub, LinkedIn, Kaggle, Twitter/X, etc.)
- Email address display
- Optional: embed a subtle call-to-action ("Let's collaborate on your next ML project")

## Navigation
- Top navigation bar with all 5 pages, sticky on scroll
- Mobile hamburger menu
- Active page highlight
- Smooth scroll-to-top on page change

## General Features
- All content is static (hardcoded) — no backend needed
- Fully responsive across all devices
- Placeholder content provided for all sections so you can easily swap in your real info
